Security & Session Architecture

Supabase Auth
  • Google OAuth 2.0: Secure federated login retrieving your name, email, and avatar URL with consent.
  • Encrypted Passwords: Zero plain-text passwords stored in PostgreSQL; hashed and verified exclusively by Supabase Auth.
  • Persistent Profile Sync: Your profile in public.user_profiles is protected by per-user Row Level Security (auth.uid() = id).
  • Email Verification & Recovery: Supports verification links and email-based password reset.
